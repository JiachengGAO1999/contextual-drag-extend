# 数值等价与资源合法性：自然失败材料的CPU核对

状态：候选解释的材料审核；没有新增模型调用，未建立新机制或MVP。
不将下面的符号恒等关系解释为模型内部的表示。

## 检验的具体解释

`a*(b+c)+d` 与 `a*b+a*c+d` 数值恒等，但后者多用一个a。
如果旧错式是合法式经代数变换得到的非法写法，那么模型或许将数值
等价错误推广为资源合法性等价。这比泛泛的“有历史会干扰判断”
更具体，但需要先核对这种关系是否实际存在于自然失败材料。

普通代数恒等式、资源线性约束以及LLM的计数困难本身不是新发现。
[TASE](https://arxiv.org/abs/2508.05468) 已评估字符计数、结构解析、
长度约束等细粒度能力，因此仅说明模型计数不准也不足以构成贡献。
当前文献检索没有证明上述具体机制新颖；不能用未搜到同名论文
推断研究空白。此前身份表示的前瞻验证没有确认稳定收益，也不因
本页的新描述而恢复别名或身份调参。

## 方法与结果

入口：`python scripts/audit_algebra_resource_equivalence_20261012.py`。
结果：`outputs/generation-diagnostics-20261005/algebra_resource_preview/audit.json`。
来源：`candidate_adoption/failure_pool.json`的48题材料池；不是480条
旧生成输出均覆盖48题。自然候选采用池中既有表达式，不筛选新题。

穷举每题使用原四张牌的所有二元四则运算表达式。先按精确有理数
保留结果为24的候选；将每种不同输入数值视为一个形式变量，相同
数值的牌共用变量。精确代入仅用于排除非恒等候选，剩余关系通过
SymPy符号消元确认。一个人为的分配律例子验证流程能找回已知关系，
该例不计入研究样本。

- 48道旧错式中，44道数值为24。
- 46道包含的数值集合与题目相同，但45道的数值多重集错误。
- 25道有直接同子树相除或相减的中性结构。
- 44道数值正确的旧式中，只有6道找到严格形式恒等的合法四牌式。

六道具体见证：

| 题号 | 旧式（资源非法） | 合法的形式恒等式 |
|---|---|---|
| 1305 | `(10/5)*(13-10/10)` | `(13*10-10)/5` |
| 753 | `8*((3+1)-8/8)` | `8*(3+1)-8` |
| 1189 | `(12*12)/(12/(12-10))` | `12*12-12*10` |
| 719 | `8*(7-(5-8/8))` | `8*(7-5)+8` |
| 44 | `12*(12/12+10/10)` | `12+12+10-10` |
| 509 | `6*((9-6)+6/6)` | `(9-6)*6+6` |

这六题均含重复输入数值，不能区分数值重复、资源身份与代数结构的
影响；也不是独立验证集。恒等关系仅在共同有定义的域成立。包括1
在内的不同输入数值均作为变量，因此此审核刻意不把依赖具体数值
巧合、将给定1当通用常数等关系叫作形式恒等。不能据6/44估计模型
采用某种内部算法的比例，也不能据其余38道否定所有形式的数值偏置。

## 原始推理能说明多少

阅读既有1305题COUNT_HISTORY候选判断（seed20261015），文本明确将
`10/10`描述为使用“第二个10”，再将旧式清点为两个10；原式实际为
三个10。它接受旧式与合法候选，却没有展示上表那种符号变换过程。

509题同条件同seed也将`6*((9-6)+6/6)`清点为三个6，而实际为四个。
这两条支持具体的错误清点描述，不证明模型先进行了代数正规化。
不能因为恰好能找到合法恒等式，就把其资源误判归因于该恒等式。
两条均来自既有原始输出，未请求新的模型生成；并非穷尽语义标注。

## 决策

严格代数修复关系确实存在于少数自然错误中，但当前不足以成为解释
大部分历史拖曳的机制。没有依据将它升级为主线或启动六题GPU矩阵。
也不将“把中间算式当一个资源”等另一个名称自动升级为新机制。

若后续研究这一问题，需要操纵数值等价关系与实际资源出现次数，
并区分一般计数困难、重复值绑定、算式分块和历史特异影响。已有的
目标值／资源双因素与subject实验没有支持之前的主交互，不能换个
名称再跑同一对照。新实验必须提供新的可区分预测和独立材料。

本轮新增脚本、数据和记录仅在本地。共享24 GPU小时已耗尽，未排队、
未启动新模型任务。项目仍未发现已验证的新增机制或稳定方法MVP。
