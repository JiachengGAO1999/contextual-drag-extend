# 下一条可否证命题：失败历史是否传递错误的检查规则？

完整解释与预算见[结果报告](check_rule_transfer_results_20261011.md)。

## 研究问题与创新边界

2026-10-11 用户指出：即使给出合法候选，失败历史仍干扰选择，这仍主要是
Contextual Drag 的现象延伸。接受这一判断，不将上一轮结束探索解释为
发现了创新机制或方法 MVP。本轮目标仍是找到原论文没有发现或解释的内容。

候选命题：历史不仅提供一个易复制的解，还可能改变模型执行哪一种检查。
例如，把“每个不同数都出现过”当作“每次出现都按原有数量计数”。如果
发生这种规则迁移，它应影响另一道题中相应约束的检查，而不只是旧式采用。
这是待检验解释，不是现有证据已经支持的结论。

区分三种解释：

1. **具体解绑定：** 主要受相同问题、相同构造影响；换成其他题后效应消失。
2. **整体宽松：** 不论旧历史错在哪里，当前算术与次数判断一起变宽松。
3. **检查规则迁移：** 历史错误的约束类别预测当前漏检类别，出现交叉选择性。

第三项若成立，比“历史仍有影响”多出一个可干预、可预测的解释；但仅凭
一次合成任务仍不能宣称神经机制、跨任务一般性或 ICLR 贡献已经成立。

## 相关工作约束

- [Contextual Drag](https://arxiv.org/html/2602.04288v1)：已报告错误反馈、
  正确自我验证后仍受干扰及结构复用。相同问题的重复验证不是新增主张。
- [Prior Audit–Repair Context](https://arxiv.org/html/2608.16003v1)：已报告
  审查历史使验证器阈值变宽松。因此一般的验证污染或宽松变化不够新；
  本实验用“历史错误类别 × 当前检查维度”的交叉效应区分整体宽松。
- [Chain-of-Verification](https://arxiv.org/abs/2309.11495)：独立验证以减少
  原答案偏见已有方法；暂不把冷启动审查或多一轮验证包装成新方法。
- [STALE](https://arxiv.org/abs/2605.06527)：状态更新与行为脱节、依赖失效
  已有直接相关工作；本轮不再把一般的依赖撤销失败作为独占研究缺口。

轻量候选比较：独立身份（已无稳定收益）、晚屏蔽（与 R3/R4 重叠）、
来源 heads 搜索（已有不支持）、纯粹独立验证（CoVe 重叠）、泛化宽松
（已有先例）、错误位置反馈（已有先例）、依赖图撤销（已有先例）、
删除错误验证句（一般去噪，尚无新预测）、跨约束检查迁移（本轮优先）、
上下文证书与当前条件匹配（后备，但与过期记忆/无关上下文重叠较大）。

## 冻结实验：另一道题、同一历史表达式的反事实合法性

复用上一轮全部 30 题及原 15/15 分组。CPU 为每题构造四个四叶表达式：
合法、仅次数错误、仅数值错误、两者皆错；全部用精确分数与叶节点计数
审核。次数错式保持四个叶节点，由一次输入数替换并 CPU 求解得到，避免
简单“叶子多于四个”捷径。只按固定顺序取首个可行式，不按模型效果筛题。
如无法构造某题则报告设计问题，不悄悄替换或启动不完整批次。

每题分配另一题为历史 donor，映射在 GPU 前冻结、双射且不跨 15/15 组。
当前题与历史题的输入不同；历史表达式不得与任一当前候选相同。
同一 donor 的历史数学表达式 E 恒定、值为 24、四个叶节点。通过改变
历史题的资源清单和目标值形成四个反事实：

| 历史条件 | 历史清单 | 历史目标 | E 的实际状态 | 反馈 |
|---|---|---:|---|---|
| VALID | E 的叶节点清单 | 24 | 全合法 | CORRECT |
| RESOURCE | donor 原清单 | 24 | 仅次数错 | INCORRECT |
| VALUE | E 的叶节点清单 | 25 | 仅数值错 | INCORRECT |
| BOTH | donor 原清单 | 25 | 两者皆错 | INCORRECT |

四种历史都含相同的两句正面验证声明，公式、声明及格式恒定。RESOURCE
与 VALUE 反馈相同，但各有一个不同的错误声明。VALID 的反馈不同，不能
用 VALID 对比单独识别错误类别。此干预改变历史题定义；其结果是该明确
反事实协议下的效应，不能称纯粹改变一个抽象“错误类别”而其他语义不变。

另设 CLEAN 无历史及 SELF 原题自然失败历史作为参照。SELF 使用本轮新
候选，不保证包含历史原式，因此不是上一轮旧候选任务的严格阳性对照；
不能由 SELF 无效推断原拖曳消失。不将其与合成历史差异直接解释成长度
或单个机制的效应。共
**30题 × 2 seeds × 6条件 = 360次自然 Thinking 验证**。每次检查四式的
`value_matches` 与 `counts_match`，不搜索新解、不选择旧式。每 seed 的
候选顺序随机冻结，同题跨条件相同。所有条件均重跑，不挪用旧分数。

首要对比，以错误认可率表示：

    资源特异效应 = FA_resource(RESOURCE) - FA_resource(VALUE)
    数值特异效应 = FA_value(VALUE) - FA_value(RESOURCE)
    交叉选择性 = 两项的平均

整体宽松若同等作用于两个维度会抵消，但维度难度和不同历史语义仍是
竞争解释，因此同时报告每个维度的真阳性/假阳性、四类候选结果、VALID/
BOTH/CLEAN、15/15 分组及每题方向。不能只展示一个有利维度。
两 seed 及同题四候选都在题内聚合，以题为统计单位。固定一对一 donor，
不把 360 请求或 1440 个候选当独立样本；不声称对任意 donor 分布泛化。

正向选择性还须来自相应错误相对 CLEAN 增加，而非只由另一维度改善
驱动；反向选择性如来自对应错误减少，应解释成错误反馈引导检查，而非
事后改名为“错误规则传播成功”。没有一致选择性则放弃本轮迁移命题。
只有 SELF 有效时，保留“具体解绑定”解释，不继续扩大这个合成矩阵。
缺失/截断单列，准确率分母保留所有请求；缺失不能算“拒绝了错误”。
