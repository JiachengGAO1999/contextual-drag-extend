目标：在未参与本轮组件选择的题目上，比较持续移除草稿贡献与同位置、
同幅度非草稿贡献移除。停止搜索 heads、幅度与窗口。

的 ID 和数字组合；每个组合按固定来源优先级取首个合格失败草稿，按 ID
排序后用种子 20261007 打乱，取前 24 题。未查询它们的新干预效果。

题单：285、1093、1226、283、651、719、685、1185、1261、1148、50、
753、577、19、1358、804、1084、776、274、353、170、1008、1139、1170。

失败资格：历史输出正常 EOS、官方评分 False、非标量最终表达式可被
精确算术解析，且未满足 Game24 的值或数字库存约束。使用既有最终草稿
正文。历史结果可能已经看过，所以只能称“未用于本轮组件选择的题目”，
不是完全未见的外部测试集。来源与早期生成协议差异保留在 manifest。

多数题缺少失败反馈后的既有自然前缀。这批只为每题补一次 FULL 短续写，
最多 2048 tokens、种子 20261007、temperature 0.6/top_p 0.95/top_k 20。
沿用独立求解的失败反馈包装和 Qwen3 Thinking；不重新生成或筛选草稿。
达到 2048 tokens 的输出作为截断前缀保存，不当作完整解答评分。
用户已在首个前缀生成前同意将采集和诊断上限从 512 提高到 2048；
题单、seed、组件、采样参数和总预算保留原冻结值。

## 先审查前缀，再测干预

第一阶段完成 24 个短前缀后释放 GPU、恢复符合条件的项目常驻，进入
`awaiting_cpu_semantic_review`。第二阶段只在语义审查与候选冻结后启动。

每题取 2048 tokens 内首次明确拒绝或认可原错误构造的事件；两种原始
方向都保留，避免只选 FULL 错误的案例。引用原文、正确局部计算和指代
不明确的断言不算认可事件。候选必须在同一自然前缀下能明确表达拒绝
与认可；审查时不看干预结果。只重放到首个经审查事件及候选完成，
不要求每次诊断跑满 2048。缺失事件记缺失，不补题或补续写。

| 条件 | 持续干预 | 固定项 |
|---|---|---|
| FULL | 无 | 自然前缀、模型、后端、评分候选 |
| CANDIDATE | 移除草稿 alpha-V 贡献 | 冻结 144 heads、幅度 1 |
| CONTROL | 移除等 norm 非草稿方向 | 相同 heads、相同时间范围 |

保留该次局部 attention weights，不重归一化。norm 在每个 head、o_proj
之前匹配，不能解释为投影后扰动相同。

主要指标为逐题 CANDIDATE−CONTROL 的拒绝/认可序列 log-prob margin
差；CANDIDATE−FULL 为辅助。报告题目 bootstrap 均值区间、正负方向、
辅助双侧精确符号检验、长度归一化指标及剔除最大正效应题的敏感性。
不把 seeds、tokens、heads 当独立题目；不因中途 p 值追加样本。
最多 72 个三条件请求；实际数量受缺失事件限制，24 个前缀不等于
24 个可评分事件，也不保证显著性。不自动桥接长生成。
