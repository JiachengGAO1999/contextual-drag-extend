## 为什么值得检验

原自然失败历史实验的候选阶段，模型判断合法性并选择答案。规则迁移
实验则分别报告算术与次数，也换了候选。前60次均全对，只能提示新的
对照，不能把跨批差异归因于某一因素。

新命题是：**要求模型采用一个答案，可能使验证转为支持采用；问题不
一定是历史已破坏了所有可用的检查能力。**如果同一历史、同一旧式和
合法式下，只要求审查时判断更可靠，而加入选择要求后旧式更容易被
错误认可，就区分了“判断先错，导致选择错”和“采用目标改变了判断”。
这里的因果对象是任务要求，不把行为结果等同内部先决定后编造理由。

例：1,6,6,10 的旧式 `(6+6)*(10/(6-1))` 用了三个6。如果让模型只判断
两式是否合法，它否定旧式；加一句“随后选择有效方案”，它却改判旧式
合法。这种同材料下的反事实变化才支持本命题。当前尚未观察到该结果。

## 相关工作与不足

- [Contextual Drag](https://arxiv.org/html/2602.04288v1)：已表明正确识错
  与重新生成能脱节；本轮不再将这一点当新发现。
- [Motivated reasoning probes](https://arxiv.org/abs/2603.17199)：提示答案
  后的事后合理化已有行为及激活证据。不能仅给合理化现象改名。
- [Task framing](https://aclanthology.org/2026.iwsds-1.21/)：事实/判断的
  任务框架影响判断已有先例。一般提示敏感性也不构成新贡献。
- [CoVe](https://arxiv.org/abs/2309.11495)：独立/分解验证已有方法。

希望增加的是**自我纠正流水线中的能力组合失效**：一个验证器在审查
目的下能否保持正确，在同一输入上兼任选择者时却丢失这个能力；以及
把当前验证与采用分开是否能在保留全部历史的情况下防止该失效。
其创新性仍需数据、竞争解释和进一步文献核对；一次 Game24 因子实验
不能单独证明广泛的新机制或 ICLR 可发表性。

## 冻结比较

使用既有同模型 Thinking 自然失败池**全部48题**，不新增筛题生成。
每题沿用自然旧错式与CPU合法式，不改变表达式、失败历史、反馈或强
次数提醒。全8条件同一新seed，候选位置在题间平衡，跨条件保持相同。
按固定种子分24/24用于方向核对；两组均为已有研究材料，不称独立留出。

2×2×2 因子：

1. CLEAN / HISTORY：无历史 / 原失败历史与明确 INCORRECT。
2. AUDIT / ADOPT：仅报告两式是否合法 / 同样判断后再选择有效式。
3. HOLISTIC / FACTORIZED：只报告整体合法性 / 额外分别报告精确数值是否
   达标、叶节点数量是否符合，再报告同样的整体合法性。

每种任务均输出整体合法性和 choice 字段；AUDIT 的 choice 为 null，
ADOPT 为1/2。FACTORIZED 额外要求四个分项布尔值。该因素确实改变了
输出内容与检查要求，不能直接说它隔离了神经模块，也不能把更多推理
或明确提示带来的普遍收益叫作历史特异机制。实际 token 成本一并报告。

共 **48×8=384次**，BF16 Qwen3-8B Thinking，vLLM，8192上限，8并发，
seed20261019。当前设计尚未看任何本批模型输出。共享预算仍24小时。

首要效应：HOLISTIC 下的

    [旧式误认可率(HISTORY,ADOPT)−旧式误认可率(HISTORY,AUDIT)]
      −[旧式误认可率(CLEAN,ADOPT)−旧式误认可率(CLEAN,AUDIT)]

FACTORIZED 同效应及其与 HOLISTIC 的差异是辅助；报告所有主效应，
不靠换首要指标挽救零结果。题为统计单位，48题配对bootstrap；缺失、
截断、历史来源与每题方向全部保留。

解释分支：

- 若采用要求仅在历史下显著增大误认可，且两预设组方向一致，支持
  任务目的介入验证。仍需排除一般任务框架变化，不直接声称内部合理化。
- 若没有采用交互，但分项检查同时大幅减少误认可，转向整体判定与
  分项能力的差异；它可能只是一般检查提示收益，不能直接叫新增机制。
- 若分项均正确却整体仍认可旧式，才有具体的约束整合失效证据；若
  没出现，就不维护这个故事。
- 若没有上述差异，停止本命题，不自动追加提示措辞或新 heads。

该实验的目的不是把几个提示排个名，而是确定下一轮机制工作应解释
“检查能力失效”“组合检查失效”还是“任务目的改变检查”。
