**最简单解释。**模型输出中的数字清点本来就错误，合法与非法式被同时接受，最终选择可以受表面形式、草稿重复或随机采样影响。44还含直接提供的正确答案。无需假定已经正确否定旧式、内部保留某种错误向量或发生撤销失败。

**尚未解释的差异。**“只是没有找到合法解”不足以描述这些具体已完成轨迹；但“约束核对错误”仍相容。需要解释的是：在两式均显式存在、旧式仍被错误认可时，哪些可测条件预测最终选择？1057的相反seed说明仅给轨迹贴认可标签无法回答。现有记录没有把式子复杂度、呈现次数、位置、错误清点和采样分别固定，无法确定各自贡献。

**区分性检验能否提出？**可以。共同评估后，先考虑将同一对合法/非法算式的数字清点表显式固定并正确提供，再独立平衡呈现顺序与复杂度。如果差异被正确清点消除，优先解释为验证不足；若在输出已准确判定旧式非法的情况下仍系统性选择旧式，才出现需要进一步解释的剩余差异。该设计改变了任务，只能检验具体竞争解释；不能自动作为自然轨迹机制的证明。本轮未构建或运行该实验。

**独立证据是否足够？**足够确认这种输出模式在两个不重合题池、多个题上存在；不足以确定发生率、历史特异性、标注稳健性或内部机制。24题仅一个seed；30题与旧主池重合，IDENTITY、早期标签和后述P3均非独立复制。

## 4. 候选 P3：提供合法候选后，清洁条件明显改善，历史条件的损失却没有消失

**观察事实。**同30题、两个既有seed，NATURAL让模型自由解题，CANDIDATES直接提供旧非法式和一个CPU确认合法式，要求分别判断并选择；候选位置随seed平衡。它们不是相同prompt，以下只是任务形式的事后交互描述。

| 表示 | 自由解题 CLEAN / HISTORY | 候选任务 CLEAN / HISTORY | 历史差：自由解题→候选任务 |
|---|---:|---:|---:|
| COUNT | 38/60 / 25/60 | 48/60 / 29/60 | −21.7pp→−31.7pp |
| IDENTITY | 34/60 / 28/60 | 49/60 / 25/60 | −10.0pp→−40.0pp |

候选任务240/240 EOS，JSON均可解析；HISTORY共66次选旧式，**66次同时错误认可旧式**；没有观察到两式合法性都判断正确却选旧式。COUNT里合法式均被判有效，错误主要在把旧式也判有效。因而这批不能用作“正确判错后仍采用”的例证。

144、seed20261015是直接的历史损伤见证：COUNT_CLEAN第361行正确判定旧式非法并选合法式；COUNT_HISTORY第369行把两式判有效，选择旧式。反向案例也保留：44两个seed的COUNT_CLEAN第403、409行均错选，COUNT_HISTORY第405、400行均正确。1057第242、244行在旧式位于选项1、2时均错误认可并选择旧式，但同seed CLEAN第245、247行也犯同样错误，因此它只支持验证困难，不能当作历史新增损伤。原始文件均为 `candidate_adoption/generations.jsonl`，评分行号相同；完整prompt、最终JSON与配对记录均已保存。

**最简单解释。**完整解的资源核对依然困难，错误草稿包含错误清点；提供另一答案并不自动修正旧式的验证。候选任务还改变了输出形式、候选竞争、上下文长度和停止方式。自由解题COUNT CLEAN/HISTORY分别18/11条length，IDENTITY为24/15条；候选任务无length。因此正确数差含不同的计算预算后果，不是纯判断能力差或纯历史利用差。

选项顺序不能忽略，但不足以作为一个已被单独证明的解释：旧式放第1/第2时，COUNT CLEAN正确22/30、26/30，HISTORY16/30、13/30；IDENTITY分别21/30、28/30和14/30、11/30。历史差在两个位置均为负。位置与seed仍共同变化，不能从这张表单独估计位置因果效应。

**尚未解释的差异。**“只是搜索不到新解”无法解释直接给出合法式后仍有66次旧式错选；“只要把生成改成容易的选择任务就解决历史干扰”也不成立。但验证不足、草稿中的清点错误和候选偏好仍能解释，没有剩余证据要求内部机制假说。值得追问的是哪些任务要求放大或减轻这种验证偏差，而不是给选择错误换一个机制名称。

**区分性检验能否提出？**可以。将候选识别与最终选择分开记录，在同候选和预算下分别提供无裁定的出现次数表、正确合法性标签或仅算术值；交叉平衡位置及seed。如果正确次数表消除旧式误认可，支持资源验证解释；如果两式判定正确后仍稳定错选，才得到另一类剩余现象。必须先共同判断是否值得做；本轮没有生成新材料或运行模型。

**独立证据是否足够？**30题内两seed、位置平衡和两个历史分层均可核对，足够说明此批候选任务仍有历史损失；不足以建立任务形式交互的独立复制。COUNT/IDENTITY、P1自然轨迹和这组候选输出共享题目，不能计成三份独立证据。不存在“新方向已确定”的结论。

## 5. 未升级为候选的观察与证据缺口

1. **草稿与非草稿移除收益接近。**72条原始行为重算为9/17/16正确（各24）；CANDIDATE对CONTROL改善4题、损伤3题，净+1/24，不是等效证明。旧式复用5/24对8/24的净差中，两条来自候选截断/无可解析解答；双方有可解析最终式的22题仅5对6。1084中CONTROL正确而CANDIDATE仍选旧式，651则相反。一般扰动与随机分歧尚未排除，来源专属性证据不足，不另凑一个机制异常。
2. **相同提示与seed不保证同一轨迹。**identity与alias在8道无重复数值题上复制了相同prompt及input_ids；16个跨批配对模型和采样字段也相同，但16/16 token序列不同、5/16正确性翻转。这是既有运行对照，不是新实验。批处理数值、运行配置或随机状态差异可能足以解释；没有执行级日志把原因分开。因此单seed净差和个例“恢复”必须保留复现不确定性，不将它升级为神经机制。
3. **数字解正确、符号答案错误的普通转换例。**1261，IDENTITY_CLEAN，第34行写出合法数字式`(11-2)*2+6`，最后映射为`((D-A)*B)+C`；实际prompt绑定为A=2、B=6、C=2、D=11，最终值56。输出却自行改成B=2、C=6。无错误历史就能出现，首先解释为绑定/转写错误，不必诉诸历史机制，也提醒P1不能将所有“见过合法式后失败”混为一类。
4. **短分数不是自然终点。**跨题重放有来源相关的局部偏好差，来源分区未获得其预期的主比较支持；744条短读出又未通过CLEAN效度门槛。不能将这些分数与自然生成正确率拼接为一条因果链。没有读取未运行的PRE/POST或移植结果来填补空缺。
5. **准确诊断的历史正例不是总体分母。**既有定向审查保存20条具体违规正例，其中15条正常结束均正确、5条截断；筛选与审查覆盖不支持总体识错率或识错的因果收益。本轮没有把剩余轨迹归为“未识错”，也没有沿此旧假说穷尽重标。
6. **代表性和独立复核仍缺。**主23题经过目标表现筛选；30题沿用失败池；UFT源输出EOS未知、长度和错误类型不同；新64题初稿61正确、2错误、1缺历史，失败历史仅2题，不能作为失败修复确认集。此前反馈解码7份预算缺失不补齐。原论文跨模型完整逐题输出不可用。本轮没有第二标注者、跨模型自然事件标签或未见材料上的候选确认。

这些缺口意味着：可以提出需要进一步解释的可观察差异；不能声称简单行为解释已经全部失败，更不能推断一个共同的内部异常类别。
