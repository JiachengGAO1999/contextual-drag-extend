# Goal 1结果与决策：STOP当前短评分协议

结论：完成Gate 0及唯一一次预定测量修正，两次均未通过无历史能力门槛。
依照冻结规则停止本协议，不进入PRE/POST确认或KV移植。
**Late Invalidation假说仍未被检验；这不是它被否定，也没有获得支持该机制的新证据。**

方案及阈值见[冻结协议](late_invalidation_goal1_20261012.md)。不追加第三种
评分前缀、不降低阈值、不换题继续尝试。当前结果不足以支持ICLR机制论文。

## 实际执行与结果

模型为服务器本地Qwen3-8B，BF16、HF SDPA、单A100 GPU4；仅forward，
没有自然生成或训练。两版各完成62题×3条件×2选项顺序＝372次，共744次，
全部完整保存、无缺失。62题包括全部30道历史Game24校准题和32道新发现题。
用时47.25秒，包含模型加载及评分；等待时间另计。此前分钟级预估偏保守。

每题先平均两种选项顺序，再在题目之间统计；置信区间为5000次题目bootstrap。
下列百分数是两候选内部归一化后的正确候选概率，**不是生成准确率**。
历史损失为CLEAN减POST，POST明确标记草稿错误。

|---|---|---:|---:|---:|---|
| r0：思考内固定前缀 | 30旧题 | 40.7% | +31.1个百分点 | [23.7, 38.0] | 未过 |
| r0：思考内固定前缀 | 32新题 | 47.8% | +24.4个百分点 | [17.7, 31.1] | 未过 |

两候选的完整词表概率质量均约99.9%，覆盖率100%；损失的幅度与区间也
通过预设要求。失败项都是CLEAN偏好低于60%的能力门槛。不能仅取历史
损失的正结果，将Gate 0判为成功。

作为不改变决策的描述，r0旧题中正确候选排第一时偏好64.1%，排第二时
17.2%；r1分别为26.0%和51.7%。选项顺序和读出前缀明显影响这一即时
读出。虽然设计已对顺序取平均，这仍提醒我们不能把它直接等同于充分推理
之后的判断。此处没有通过额外实验定位这种依赖的原因。

## 可以说明什么

同题加入错误草稿之后，模型在两个短读出中都更偏向旧错误答案。这是一个
局限于该评分任务的历史影响，与Contextual Drag相容；不是新的机制贡献。

但模型在没有错误历史时，也未表现出预设的正确候选识别能力。因此短评分
尚不能可靠区分“已能求解却被历史拖偏”和“尚未完成必要计算就被要求作答”。
我们测到的可能包含答案复制、选项偏好及缺少推理等因素，现有数据不能分解。

例如，旧题1057要求6、9、9、12各用一次：合法候选为
`(9+12)-(6-9)`，旧错误式为`6*((12-9)+(9/9))`。后者虽然等于24，
却用了三个9。当前协议直接续写“正确答案是选项…”，没有让模型先完成
使用次数核对。低CLEAN表现不能解释成“模型已认清这个错误却未撤销它”。

## 各gate的终态与证据边界

| 阶段 | 状态 | 对研究决策的含义 |
|---|---|---|
| 材料与协议 | 冻结完成；真实tokenizer检查通过 | 可复用输入构建、位置匹配和题目级统计实现 |
| Gate 0 | r0、r1均未通过 | 当前短读出未获测量效度支持 |
| Gate 1 | 未启动 | 没有PRE/POST配对结果，不能声称有差异或等效 |
| Gate 2 | 未启动 | 没有KV/activation因果证据；条件不满足，不开发移植矩阵 |
| Gate 3 | STOP当前协议 | 无依据进入ICLR机制论文开发，也未否定Late Invalidation总体假说 |

128道新题的32发现/96确认划分在任何评分前已冻结，排除了source-binding的64题。
96道确认题仅完成输入编译，**模型评分为0**。编译不算打开确认集；缺失的
PRE/POST结果是门控后未执行，不是效应为0或样本失败。

题目去重不能保证数学题型、训练来源或生成模型相互独立。新题真值沿用公开
教师标注库，没有逐题独立证明参考解；30旧题是既有同模型失败历史，存在
校准选择条件。这里也没有自然生成桥接、跨模型或跨数据集泛化证据。

创新边界：仅观察失败历史拖偏候选选择，与既有Contextual Drag现象重合；
尚无标签时机特异性、内部状态的因果关联或可泛化机制。架构的KV不回写
不能替代这些证据。因此本轮不将正向历史损失包装成Late Invalidation机制。

后续如重启这条路线，需要先提出新的、有独立理由支持的测量方案，例如
允许必要计算后再取判断读出，并明确它对研究决策的价值；这将是新协议，
不能作为本轮第三次修正或在这96题上调参。本轮不自动启动该方案或其他方向。
