## 候选升级：撤销的对象与依赖边界

需要研究的不是一般“历史仍有影响”，而是否能撤销特定错误的
求解作用：被否定步骤及依赖该步骤的构造应失去支持，独立正确的
子结果应仍可利用。候选解释是反馈改变了对草稿的总体评价，却未
相应改变按依赖关系使用信息的方式。该解释可能不成立；也不预设
Transformer 架构无法实现撤销。

受控材料拟在同一草稿中包含可精确验证的错误步骤、依赖错误的后续
步骤及独立正确步骤。先比较相同草稿下的一般错误反馈与准确指向
错误步骤的反馈；固定读出，分别评分继续采用错误依赖与利用独立
正确信息。数字、步骤数量、依赖深度等匹配细节仍待确定。

这一行为比较只检验对象选择性及反馈粒度，不能单独证明内部机制。
若具体反馈已解决问题，优先解释为反馈不足；若同时削弱所有步骤，
优先解释为一般历史利用变化；若明确拒绝后仍选择性沿错误依赖
继续，才值得设计一次针对承载该依赖计算的因果干预。干预不从新的
head/窗口搜索起步，也不把正确步骤利用率不显著下降当作无损证明。

## 立即推进顺序

1. 用已有论文、自然轨迹和来源分区结果评估上述候选解释；不要求
   全部长轨迹重标作为启动门槛，也不把代表性案例当作发生率。
2. 在冻结 GPU 配置前核对相邻工作的重合，完成一个精确算术可验、
   可批量构造的最小材料示例，并写明竞争解释及方向相反的预测。
3. 只有该比较能决定继续或放弃核心命题，才替换/修订现有待启动
   批次。不自动并行启动两个矩阵，不沿用旧 384 单元规模作为目标。
4. 有区分力的受控结果出现后，再用未参与设计的自然生成检验预测；
   否则停止该解释，保留已有访问控制结果，重新选题。

该候选方向的价值取决于能否解释并预测撤销成败，不来自“混合历史”
材料本身，也不来自增加样本或改进统计显著性。
