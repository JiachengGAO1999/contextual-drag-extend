# 创新判断与停止清单

目标仍是找到超出原Contextual Drag的解释或可用idea。以下区分已有
发现、当前证据和待检验解释，不因已有代码或剩余预算而自动开新批。

2026-10-12 [反馈方向解码已结束](feedback_decoding_results_20261012.md)：
共享24小时预算耗尽，73/80完成并下载；真实反馈的11对0恢复、3损伤，
首要均值−27.27pp。未完成请求的有限题单边界也不能使净收益转正。
停止这一固定幅度MVP，不扫系数，不将其负结果解释为所有反馈指导
无效。目前没有确认的新机制或稳定方法，不能将目标标为完成。

2026-10-12新候选的CPU检查见[反馈信息充分性](feedback_evidence_sufficiency_20261012.md)。
反馈选择／停止规则决定哪些历史事实可被认证；首错与抽查不能共用
未经校正的前缀认证摘要。穷举只是构造反例，没有模型证据或新颖性
结论。Feedback That Backfires已有动作／消息分解和失败抽象，CORE
已有经认证冲突缓存，GeoPlanner已有前缀保留；这些裸方案不再提作
新方法。若推进，需检验反馈规则依赖的预测，而不是再跑一个摘要
优于原文的提示矩阵。没有新执行题单或GPU请求。

2026-10-12：[原论文v2核对](original_v2_review_20261012.md)确认已有复用
指令消融及GRPO比较；历史v1链接不能作为完整新颖性边界。
[错误类型CPU预览](error_profile_feasibility_20261012.md)仅5/30题满足
严格材料匹配，尚未形成独立验证方案，不自动提交GPU。
同页补充局部可达性审核：76个未超用库存的非根子树，18个可延伸、
58个不可延伸；这是既有规划概念在材料上的诊断，不是模型行为或
新的机制。不能仅凭“正确步骤不一定有用”再启动一个提示矩阵。
另见[公开定位数据检查](public_localization_data_review_20261012.md)：
Thought-ICS已有分步定位、回退及保留失败链的实现；已下载一份40题
初始链缓存，但没有准确定位后的续写标签，不据此宣称独立机制复现。

## 当前证据不支持哪些故事

| 解释 | 当前证据 | 决策 |
|---|---|---|
| 已经正确识错，却仍选择错式 | 原候选实验有历史66次错选均同时误认可旧式；没观察到全部合法性判断正确后错选 | 不以此作为已发现机制 |
| 外部错误历史迁移一种错误检查规则 | 新四叶候选360/360分项全对，有天花板 | 停止该合成迁移协议 |
| 为了最终采用而扭曲审查 | 原候选384次同材料因子实验，首要交互−2.08pp，区间跨零，两组反向 | 不追加措辞或选择辅助指标挽救 |
| 数值目标满足遮蔽次数违规 | 480次已完成，历史×目标交互−2.08pp，区间跨零 | 停止；不启动目标反平衡预览 |
| 同对象附加计算调用历史检查摘要 | 576次完成，历史×对象交互0pp，区间[−20.83,+20.83]，两组反向 | 停止；不追加可见目标/schema小矩阵 |
| 独立身份是稳定修复方法 | 新材料及原候选的验证未建立稳定收益 | 不继续调字母命名 |

原论文已发现历史干扰、错误结构复用、外部/自我识错不足、训练修复的
利用率权衡。这些只能作为研究动机，不能再次命名后当核心贡献。

## 相邻工作的实质重合

- [Contextual Drag](https://arxiv.org/html/2602.04288v1)：上述现象已有。
- [CoVe](https://arxiv.org/html/2309.11495v2#S3.SS3)：明确比较joint、
  2-step、factored验证，并讨论原响应和不同答案上下文之间的干扰。
  **只问次数优于联合检查，不是新方法。**保留历史的分项收益仍需
  排除任务负担、可见目标、生成长度等因素，不能先说是新机制。
- [WhatCounts](https://arxiv.org/html/2601.21618v1)：算法性计数也受语义
  内容影响；“语义干扰字面计数”不是可以直接据为首次发现的故事。
- [Conditional constraint activation](https://arxiv.org/html/2608.12321v1)：
  已区分约束可表示与是否路由到决策，泛化的“知道却不用”不足以新颖。
- [Prior audit context](https://arxiv.org/html/2608.16003v1)：已有验证阈值
  宽松化；仅历史使判定宽松不足以新颖。
- [Self-verification limitations](https://arxiv.org/html/2402.08115v2)：
  Game24验证失误、求值与整体判定不一致、目标可见性对求值的影响已有。
- [Constraint Saturation Evaluation](https://arxiv.org/html/2608.12426v1)：
  已分析多约束生成与共失败。其相关性结果不等于本项目的固定对象干预，
  但“多个检查比一个难”本身也不是足够强的新解释。
- [Why Stop at One Error?](https://aclanthology.org/2025.emnlp-main.878/)及
  [CRED verifier study](https://ape.socialcatalystlab.org/verify)：已有多错误
  检测困难或干扰。不能将反向耦合草率命名为首次发现的单错误偏见。

## 这轮结束后的决定

完整结果见[目标反事实报告](constraint_coupling_results_20261011.md)。辅助
counts-only收益存在，但与CoVe重合；不作为新的机制或方法MVP。目标
反平衡预览已明确停止GPU，以下保留原决策规则。

[附加计算对象切换](subject_gated_verification_results_20261011.md)已完成，
首要预测未获支持，停止该支。当前最新依据是
[自然识错语义复核](recognition_semantics_review_20261011.md)：截至10月12日
20条人工确认的具体违规正例，15正常结束均答对、5截断，至少4条先出现合法式。
它不能证明诊断导致恢复，但不足以支撑继续默认“准确诊断后撤销失败”。

下一阶段先核对这一语义前提。笼统verdict与具体诊断的区别已有先例；
oracle错误位置帮助修复也已有Tyen等工作，不能将其普通收益重命名。
正反反馈logit差的基本形式与Instructive Decoding重合，未因此启动GPU。
需明确一个能改变现有解释的新预测，才重新提交模型实验。

2026-10-12新选择：[反馈方向解码MVP](feedback_decoding_20261012.md)。本轮
不以新公式为贡献，而检验保留相同草稿时，放大真实/反向二元反馈
是否产生可区分的自然生成效应，并读取正确草稿利用的损伤。与有/无
草稿解码及一般反馈CFG重合的部分均已注明；80请求、固定幅度、无扩展。
若仅一般准确率提升、方向控制不一致，不能说发现反馈利用机制。

2026-10-12补充：审阅23条仍复用旧式的关键词窗口，并完整阅读五条
无窗口轨迹，合计21条、15题明确错报原式次数。部分轨迹已经找到合法
替代式仍误认可并提交旧式；这排除纯搜索解释，却不等于准确诊断后
撤销失败，也不足以单独作为创新。共享子构造诊断的边界案例仍只有
1条，未支持跨题机制，不能
继续围绕该孤例开矩阵。原六模型TED缓存经过可能改变数值/发生项的
转换，已做[CPU复核](ted_conversion_review_20261012.md)，停止将缓存公式
的错误类型当原始错误类型。解析问题是测量发现，不能直接当ICLR
贡献或宣称原论文全部无效；近期本项目的精确评分未使用该函数。

1. 优先读取首要交叉效应与预设题组。平均零且区间宽，是未支持，
   不是总体等于零；也不值得为追显著性继续扩这48题。
2. 若只有counts-only收益，保留为已知独立验证基线，不直接扩生成，
   不将辅助收益改称首要机制证据。
3. 仅当有值得解释的目标敏感性，才评估反平衡目标值是否值得GPU。
   已在CPU准备全48题单运算符改动预览：两公式只差一个运算符，叶节点、
   顺序、括号均相同；两目标交叉，192项真值审核通过。文件在
   `outputs/generation-diagnostics-20261005/constraint_coupling/counterbalanced_preview.json`。
   **它不是执行manifest，未提交GPU，也不单独构成启动理由。**
4. 若原命题与明确替代解释均无增量，回到方向选择；不以更多heads、
   更短窗口、更窄claim或一般提示收益完成研究目标。

原始结果、协议状态及预算以各实验目录为准。本文件的定位是避免
重复发现已有现象，不是以文献相似性否定一切可能的增量。真正的新
贡献应给出已有解释不能推出的预测，并用有区分力的证据检验。
