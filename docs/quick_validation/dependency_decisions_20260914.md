分别记录算术/用数正确性、当时接受或否决状态、后续实际复用。被否决不自动等于被放弃；算术正确不排除其为违规最终构造的前驱。

Target ancestor要求明确的文本结构、结果或资源状态延续。被否决且不再参与的旁路候选排除。后续依赖不明确则不进入新的primary对比，保留exploratory。标签不由旧干预准确率反推；有害/保护作用仍需实验，不在此判定。
