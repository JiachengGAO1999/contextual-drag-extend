# Contextual Drag 扩展：实验与机制讨论稿

截至 2026-09-13；供组内讨论。所有数字来自已保存的运行记录，不是计划值。

## 1. 先回答当前的困惑

**在当前十道 Game24 题、四组配对 seeds、固定 prompt 和 M_X 标注下，局部遮挡的总体正确率确实低于整段遮挡。** late：60% 对 72.5%；path：62.5% 对 77.5%。因此，如果当前目标只是提高这批题的准确率，整段遮挡是更强的已测方案。

但现有证据还不能支持“精细 mask 一般不如整段 mask”。我们测的是一种特定局部策略：遮挡选定完整错误表达式的显式副本。它没有覆盖所有错误、分步重建、相关解释、错误认证和传播后状态。**执行位置精确，不等于有害信息定位完整。** 当前也没有训练或验证一个能自动选择最优 mask 的模块。

建议在讨论中使用以下结论：

> 在这个小规模、预选的 Game24 设置中，整段访问阻断有重复的净恢复迹象；选定错误表达式的局部阻断也有部分恢复，但尚不足以复现整段阻断的总体收益。局部 path 相对 late 没有稳定净优势。结果支持继续研究访问与恢复的关系，但没有完成错误传播责任的定位，也未证明局部策略优于整段策略。

## 2. 原始问题与目前真正检验到的层级

| 层级 | 要检验的问题 | 当前状态 |
|---|---|---|
| Contextual drag | 暴露错误草稿是否降低准确率？ | 当前新 prompt 下 R0 70%、R1 37.5%，存在下降 |

## 3. 数据与共同实验设置

- 任务：Game24，使用给定四个数字各一次及四则运算、括号构造24。
- 模型：真实 Qwen3-8B，权重只读使用 `/data2/huangrj/models/qwen3-8b`。
- 科学运行：Thinking，temperature=0.6、top_p=0.95、top_k=20、context=32768；生成预算为32768减完整 prompt token数。
- 后端：自有 Hugging Face eager attention，BF16，float32 sampling。当前条件间后端一致；不把它称作与原论文 vLLM 后端完全一致的复现。
- 题目来源：原始 Game24 pool 中用模型多次采样，选择同时出现成功和失败响应的题，固定其 failed draft。未重新构造原论文三个 anchor models 的653题子集。
- 草稿使用保存的 final response，剥离采样时的 Thinking；后续评测输出保存完整 Thinking 和 final response。
- 十题：1189、1358、804、123、577、71、719、513、1084、1226。
- 汇总使用每题四组 seed bases：2027、12027、22027、32027。实际 sample_seed 包含原题索引偏移，保存在请求中；同一题同一组各条件一致。
- 使用官方 Game24 scorer。不可评分和长度截断不剔除，按不正确计入 accuracy；不因推理正文曾出现正确答案而人工改分。
- CI：整道题重采样，保留题内四组配对 seeds，10000次，bootstrap seed2027。题目独立单位是10，不是40；未单独重采样题内 seeds，也未作多重比较校正。

这是选定题集上的探索性扩展，不是原论文完整 benchmark 复现，也不是对原始 pool 的无偏准确率估计。

## 4. 当前 prompt 与五条件

R2–R4 共用的文本结构如下，R0省去草稿部分，R1去掉“最终答案错误”的提示：

```text
Original problem:
{problem}

The following draft has an INCORRECT final answer.
-- beginning of the draft --
{draft}
-- end of the draft --

Solve the original problem independently and provide a complete solution.
You do not need to evaluate or refer to any preceding draft.
Conclude with an expression using the original four numbers exactly once in \boxed{}.
```

| 条件 | 文本 | 可访问性 |
|---|---|---|
| R0 | 直接解原题，无草稿 | 普通 causal attention |
| R1 | 原题＋错误草稿，无错误提示 | 全部可访问 |
| R2 | 同上，明确提示最终答案错误 | 全部可访问 |
| R3 | 与R2文本完全相同 | 整段草稿 late_block |
| R4 | 与R2文本完全相同 | 整段草稿 path_block |

早期 prompt 要求审阅草稿，阻断后部分输出说草稿缺失。改为独立解题后，输出改善，随后在冻结的新 prompt 上做重复与扩题。**独立解题指令和答案格式要求同时改变，不能把效果唯一归因于“缓解缺失困惑”。** 旧 prompt 结果不与当前结果合并。

## 5. mask 到底改变了什么

设完整 prompt 长度为P，query的绝对位置为q；被选区间为半开区间 `[a_i,b_i)`。所有mask均叠加在普通 causal attention 上，并作用于全部注意力层。

### late_block

完整 prefill 不变。当 `q >= P` 时，禁止该query读取被选区间内的keys。**第一个生成token来自完整prefill的最后位置logits，因此尚未受到late干预。** 后续token的计算才使用阻断后的访问。

这意味着草稿信息在prefill中可以先进入后续草稿位置或提示后缀。局部late保留的这些位置仍可被读取；即使整段late阻断了全部草稿keys，提示后缀状态和首token仍可能携带影响。不能把late描述成“完全清除了草稿信息”。

### path_block

对每个编译后区间 `[a_i,b_i)`，所有 `q >= b_i` 的query都不能读取其keys，包括后续草稿、后缀和生成位置。该区间内部仍保持普通causal读取。

例如区间 `[2,4)`、`[7,9)`：q从4起不能读keys2–3；q从9起不能读keys7–8。q=8能读自身区间的key7，但不能读前一区间的key2。中间未选文字保持可读，但不能通过attention获得前一被屏蔽区间的内容。

整段R4是只有一个完整草稿区间的特例。多区间path在每个区间结束时就开始阻断，**不只是到整段草稿结束后才阻断**。它会改变prefill，首token分布也可能改变。

### 与直接删除/重置的区别

当前是logical attention blocking：不删除文本、不改变token序列或position、不物理移除KV。草稿标记、错误提示、未选内容仍然存在。R0的输入则根本没有草稿，长度、位置、任务上下文均不同，因此R4不等于R0。

本文不把“系统清空历史后重新问一次”直接等同于原论文所有reset实现，也没有做与论文reset策略的严格同配置比较。

### 字符到token的映射

在完整prompt tokenization后，取覆盖被选字符范围的最小token span；记录boundary spillover，格式字符可接受，跨入未授权语义正文则报错。多个区间合并重叠和相邻部分，不取包含中间空隙的大外包络。冻结后使用编译结果，不根据评测效果重划区间。

## 7. 局部mask具体选择什么

### 第一轮：单区间

- L_A：最后的答案区间。
- L_E：人工标注的首次未纠正错误步骤区间；不是所有后续错误。
- L_CA/L_CE：对应遮挡长度的控制区间。

四诊断题，每条件16次：R2=5、整段R3=9、整段R4=11；L_A=4、L_E=2、L_CA=2、L_CE=7。全部EOS、可评分，下降不是由截断或parser失败造成。

后续输出仍可从其他位置读取同一表达式，因此“某处遮挡无恢复”不能证明该内容不重要。单区间控制和后续多区间控制的取法并不完全相同，不能只用跨轮差值进行归因。

### 第二轮：多区间

- M_X：选定完整错误表达式的显式副本，包括正文、重复展示及答案中的该构造；不是全部错误信息。
- M_V：标注的错误合法性认证语句。
- M_XV：两者并集。
- M_CX/M_CV/M_CXV：各自等unique-token数量的前置区域控制。

四题16次：M_X=10、M_V=4、M_XV=8；控制分别5、5、6。M_X比整段R3仅多一次。加遮认证并没有单调改善（XV比X少两次正确）。这不等于认证一定有益，只表明多遮一点并不必然恢复更多。

M_X包括部分明确被否决的同式副本，标签保留其状态；不声称这些位置都被草稿认可。分步子表达式、其他错误候选、推测性descendants仍未纳入。513有多种错误候选，尤其不能称为“把该题所有错误遮完了”。

### 等token控制的实际含义

从已审阅的错误前置区域，取开头连续N个token，N等于目标区间去重后的token数。原四题控制冻结；新增六题沿用规则。目标与控制不重叠。

它只匹配token量，没有匹配位置、片段数、语义作用或path开始生效的位置。71的目标有14段、共356tokens，控制是一段356tokens前缀，含正确计算的失败尝试。边界甚至会落在`≈15.27`的`1`之后。这是已知限制：控制不是完全中性的placebo，可能改变可用推理资源或局部读取结构。

## 9. 输出中看到什么，哪些只是猜测

**513：局部path有明显题内恢复，但不具目标特异性。** M_X仅1/4，P_X为4/4。late失败重用了9或13；path四次找到`3*(9-13/13)`的等价正确式。然而P_CX也是4/4，因此不能把恢复独归因于选定错误表达式。

**577：更早阻断可以损伤。** M_X为4/4、P_X为2/4；path失败重新给出`(13-6+1)*(9-6)`，或改成`(13-1)*(6/(9-6))`，均重复6。该题R2本来就是4/4，没有这组样本上的残余下降可供恢复。

**1358：问题不仅是照抄最后公式。** M_X为0/4，P_X为1/4，唯一正确式`(13*5+7)/3`；其余继续误用`7-7`或`7/7`。早期R0也常出现同类错误，说明模型自身解题倾向可能参与，不能全部视为草稿传染。

与现象相容、但尚未被区分的解释：

1. 完整公式之外的子表达式、错误合理化和任务框架仍能重建错误。
2. late的完整prefill保留间接影响；path改变了这部分，但同时可能移除有助于纠错的信息。
3. 整段mask同时移除更多内容、更大范围的访问路径，其优势不能直接定位为某一类语义作用。
4. 当前题目与采样规模小，很多题只有一两次变化，随机性和题间异质性很大。

这些解释不是已经证实的内部机制。输出文本是诊断线索，不能替代因果对照。

## 11. 建议带去讨论的决策问题

1. **论文主张是什么？** 若主要是性能恢复，整段阻断应当作为强基线；若主要是解释传播责任，局部干预不必胜过整段，但需要更好的定位与对照证据。
2. **何为局部策略的成功？** 是更少token达到接近整段收益，还是语义特异性、较少伤害、保留有用上下文？目前没有预先定义完整的收益—遮挡量评价标准。
3. **先改控制还是先扩覆盖？** 当前建议先审阅不匹配的控制及恢复/损伤案例，再选择小规模新对照；不要直接按低分题扩大mask直到效果变好。
4. **如何避免循环验证？** 这十题已经用于多轮设计，今后修改规则后应保留新的独立题作为验证集，明确区分探索与确认。
5. **是否需要继续追求统一path优势？** 当前没有证据要求所有题path都优于late；可以把时机作为条件依赖因素，而不是预设严格等级。

本文件不启动新任务，也不把这些建议视为已授权的新实验。当前GPU4处于Qwen3常驻状态。
