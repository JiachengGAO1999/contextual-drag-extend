# 多区间late实验：冻结设计与自审结论

用户授权完成模块/标注/测试，自行审阅通过后启动服务器实验，无需逐条用户确认。通过标准是覆盖证据、执行正确与可解释性，不是恢复率。

## 实现

新增multi_region.py将明确字符证据映射至token集合并合并重叠/相邻区间；不把多个区间取外包络。请求新增mask_token_spans，draft_token_span仍保持完整草稿范围，旧请求兼容。只支持late，显式拒绝多区间path。full prefill、首token边界及其余生成参数不变。空标注/语义spillover/越界失败，不回退整段屏蔽。

45项回归与新测试通过，覆盖区间之间保持可见、单区间兼容、序列化、合并、文本匹配与异常拒绝。十题标注均可编译，96条固定输入和seed预检通过。GPU真实检查在正式生成前逐个执行四题×六条件：目标每个span的attention为0，未遮草稿仍有正attention，总36层；不要求保留区attention数值与原模型相同（归一化本来会变化）。生成逐条验证首token等于原R2。

## 标注范围

十题源草稿与原文证据见multi_region_annotations_20260912.json，文字审计见multi_region_annotation_audit_20260912.md。候选规则用操作数顺序筛选，人工核对公式结构、数值/用数约束；已修正71同数字但不同公式的误匹配，补入123纯文本副本及123/1226/1358遗漏声明。该规则不是已验证通用语义等价算法。

X=选定完整错误构造的显式副本；V=列明的错误合法性认证；XV=并集。包括被否决位置的相同完整表达式时，明确标记其状态，不能说该处被认可。正确局部算式、分步骤重建、任务要求、推测性descendants不纳入。513包含多种失败候选，认证与具体表达式的关联并非一一对应；本轮不运行513，避免把诊断清单误作已验证全语义标签。覆盖完整仅指JSON列明集合，不是所有可恢复语义信息。

CX/CV/CXV为各自相同unique-token预算的已审计前置说明区前缀，统一规则，不按效果挑位置。目标间和不同控制间可能重叠；对照不匹配碎片数量、位置、语义作用，仍是重要限制。自审中将后缀控制改成前缀，避免1358控制遮到正确的漏数批评；修改发生在生成前。原题干在草稿外保持不变，控制会遮部分草稿内的数字/约束重述。

每组输入直接复用R2 bundle，HF eager BF16/float32 sampling、Thinking .6/.95/top_k20/context32768，按原prompt长度确定预算；不改prompt/token/position/scorer。仅改变生成query可访问的keys。R2、整段R3/R4和上一轮局部mask结果作为已有参照，但X与先前boxed-only的格式范围不完全相同，577的X只有一处完整公式，不是多副本测试。

## 预注册分析

主看accuracy、M_X−M_CX、M_V−M_CV、M_XV−M_CXV及相对R2/整段R3恢复与伤害。M_XV−M_X衡量额外认证遮挡后的总变化，但遮挡量也增加，必须连同匹配控制解释，不能直接当纯认证因果贡献。保留所有length/不可评分为失败；按题bootstrap仅作探索参考（4道按既有表现选的题）。辅助看错误表达式再采用、Thinking/Final反转与用数核验。没有按结果修改标注或停止种子的规则。
