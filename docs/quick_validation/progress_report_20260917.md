## 研究问题与实现

最初问题是：错误草稿造成 contextual drag 后，阻断对错误内容的访问，能否恢复解题表现；哪些内容及传播路径承担这种影响？观察真实草稿后，问题扩展为：在反复尝试、否定、修补与认可的轨迹中，候选公式、局部计算和有效性评价分别如何影响下一次解题。

任务为 Game24，模型 Qwen3-8B Thinking，temperature=0.6、top_p=0.95、top_k=20、context=32768。十题为经过筛选并反复探索的开发集；不是原论文精确 653 题复现，也不是独立测试集。

- R0：不暴露错误草稿，重新解题；R1：暴露草稿但没有明确错误信号；R2：暴露草稿并明确告知错误。
- R3 / late_block：完整 prefill，随后阻断生成 query 对选定草稿 key 的访问；首 token 仍来自完整 prefill logits。
- R4 / path_block：在 prefill 和生成阶段，阻断单元结束之后的 query 对该单元 key 的访问；固定基本单元内部传播保留。
- X：选定完整错误候选公式的副本；CALC：关联的独立局部计算片段；X+CALC：两者联合。

干预保留输入文本、token 和 position，是 logical attention blocking，不是删除历史、物理 KV eviction 或直接 reset。局部 path 与整段 path 的单元内部边界不同，不能简单视作同一阶梯的相邻覆盖量。

## 判断与限制

1. **支持继续研究恢复现象。** 同一开发集上，整段阻断相对 R2 有明显恢复；公式级干预也有可研究信号。
2. **尚未建立局部传播责任的可靠定位。** 扩大覆盖未呈单调改善；关联内容可能同时包含重建错误和重新求解的信息。文本依赖标签不是内部因果传播的证明。
3. **CALC 的保护作用仍是假说。** late 两批中联合遮挡均低于 X，但 path 新批次差为0，区间宽且题间异质；也可能涉及一般扰动、输出完成率及与其他片段的交互。
4. **首要缺口是开发集之外的复现，而非继续解释个别 seed。** 多次在同十题修改 prompt、标注、条件，存在选择偏差；增加同题 seeds 不能替代增加独立题目。
5. X+CALC 高于/低于 X 都不能直接证明第二条传播路径或有用支架。若要作语义特异性结论，还需要可实现的控制，并报告匹配误差。
