## 唯一核心预测

如果旧草稿的影响已经进入其后的表示，那么在相同可见前缀下，
**仅在当前决策时屏蔽原草稿，与在屏蔽草稿条件下重建下游状态，
应对后续旧路线采用产生不同影响。**

要检验的是历史读取产生的下游状态是否仍有因果作用，以及这种作用
是否与旧构造身份和后续采用有关。不能仅凭晚屏蔽无效就断言“状态污染”。
普通缓存清空后原样重算不是这一实验，会重新计算相同的信息条件。

## 先做 CPU 材料与文献工作

1. 用已有 24 题 FULL 轨迹定位可核验的“明确正确拒绝→后续实际采用”
   事件对，并记录审阅覆盖；不把关键词命中自动当作首次事件。需要
   首次位置或全题现象比例时再完成全文事件审查，未审完保留未知。
   其余48条用于后续恢复／损伤解释。既有 first-verdict 探针不能自动
   当作“识错之后采用”探针。本批固定受控前缀不依赖自然首次事件，
   因此不将完整重标24条长轨迹作为受控检验的工程启动门槛。
2. 冻结相互独立的判决与采用指标。采用要求把原构造用于当前求解，
   引用、转述、检查和合法子计算都不能自动算错误路线采用。
3. 区分两套材料：自然轨迹用于发现和现实案例；拟用 32 道新的数字
   组合做受控检验，题目按预定种子/顺序选取，排除所有既有实验组合，
   不按模型失败或干预效应选题。已扫描本地 212 个历史来源文件，排除
   226 个已记录组合；按种子 20261010 获得 32 题，另保留 17 个 CPU
   材料不适用记录。未新增长 CoT 筛题；这不声明模型预训练未见过这些组合。
4. 受控材料拟包含每题两个不同失败构造 A/B 和一致规则的真实错误
   反馈；使用短、固定的后续前缀。错误类型、候选续写、顺序和缺失
   规则在 GPU 运行前固定。外部反馈/强制前缀不能冒充自然自我识错。
   材料不足时报告实际覆盖，不挑选出现预期现象的题补齐。
5. 内容身份对照要包含合法继续方案，不能强迫模型在两个错误答案间
   二选一。候选需要在上下文中自然；不用正确解泄露来制造恢复。

## 一个主实验矩阵

在每个历史版本内保持题目、完整可见文本、token IDs、位置、反馈与
后续前缀一致。唯一变化是后续状态建立时能否读取原草稿。

| 条件 | 决策前状态怎样建立 | 目标判决/采用位置能否读原草稿 |
|---|---|---|
| FULL | 正常读取并重放前缀 | 能 |
| LATE_BLOCK | 正常建立状态 | 不能 |
| REBUILD_BLOCKED | 在草稿读取被阻断时重新建立草稿后的状态 | 不能 |

主要比较 REBUILD_BLOCKED 与 LATE_BLOCK；FULL 用于描述直接读取的贡献。
草稿屏蔽按功能定义覆盖所有层和 heads，不搜索新的候选组件或幅度。
这与现有 144-head value 移除是不同干预，旧分数不能直接当作本批 FULL。

REBUILD_BLOCKED 需覆盖 F（草稿后的 prompt）及 G（生成前缀），不能
只改 G 而留下 F 的读取路径。保留原草稿 token 的占位、原文本及位置；
在重建时屏蔽草稿外 queries 对 D 的 attention。P 不受未来草稿影响，
D 内部表示保持原计算。代码审查发现这正是现有整段 R4 / PATH_BLOCK
mask，直接复用 `masks.py`，不重复开发。独立评分入口不修改旧诊断后端的
“不干预 prefill”保护。历史 R3/R4 已有行为对比，不能把相同 mask 换名
视作新增机制；本次差别是相同文本、决策前共同读取条件、A/B 身份与双读出。

在评分分叉前，从固定 critique 的最后一个 query 开始，LATE_BLOCK 与
REBUILD_BLOCKED 都屏蔽 D，之后的读出提示与候选 queries 也都屏蔽 D。
因此首个候选 token 已来自共同读取条件。两个条件此前的状态建立路径不同，
不要求它们的首 token logits 相同。FULL 始终正常读取。各评分分支 KV 独立。

只做针对新 mask/边界及原样重建一致性的最小测试，不重复整批模型验收。

## 两类结果与内容对照

- 判决：收到真实外部反馈并强制重放正确拒绝文本后，继续保持拒绝／转为认可
  的偏好。本受控读出不测量自然识错，也不把重述反馈等同独立核验能力。
- 采用：继续使用旧错误构造/转向合法继续方案的偏好；不能复用上一项
  拒绝指标并重新命名成路线采用。
- 内容身份：换成失败构造 A 或 B 后，残留影响是否跟随具体旧构造，
  而非统一变得更犹豫、更容易拒绝或降低所有候选的流畅度。

A/B 在 D 外的 token IDs 与位置严格相同；REBUILD_BLOCKED 完全阻断 D
向后传播后，两种历史的后续状态应一致。因此该条件身份效应为零是计算图
决定的验收性质，不是研究发现。需要观察的是 LATE_BLOCK 是否仍携带并使用
具体历史身份，以及这种残留是否推动错误采用、而不是只增加候选熟悉度。

主要效应是状态重建对路线采用的题目配对变化；判决变化和历史身份
交互用于解释是否具有功能及内容特异性。预先固定差值符号和候选，
报告按题结果、配对均值/区间、长度归一化结果和缺失，不把 tokens、
两个历史版本或 heads 当独立题目。

“判决差不显著”不能当成判决功能等效或不受影响。若路线与判决
一起改善，证据支持较一般的历史影响，尚不足以支持两种功能分离。
固定前缀中的文本仍能携带旧路线；本实验识别的是相同文本之外的
历史读取路径影响。重建无效不能排除文本中介或所有下游机制。

## 规模与资源

已冻结 32 题 × 2 个历史版本 × 3 种状态 × 2 类读出 = 384 个评分单元。
每个单元包含经审查候选的 teacher-forcing 评分；不是 384 次长生成。
优先使用短受控前缀，共同前缀和每种状态复用。GPU 上只同时保留需要
的分支，避免一张 A100 上复制多份完整模型。

单 A100、Qwen3-8B BF16、无训练。实际固定前缀只有 138–145 tokens，
此前 4–6 GPU 小时属于未经测量的粗估，不继续用作 ETA。将固定前两题作为
计时样本并计入本批；题单和规模已经冻结，预算不足则停止并保留缺失，
不根据观察效应重选题或规模，不越过原 24 小时总上限。

现有来源分区约需 1–2 小时，剩余总预算最近核验约 9.86 小时、inactive。
这些数字是本文件建立时快照，正式启动前仍查真实预算。来源分区用于
辅助解释来源效应，不负责在新主实验中挑 heads 或选择题目。

若主实验支持预测且预算允许，按事先顺序取 8 题，每题一个 paired seed，
仅对 LATE_BLOCK/REBUILD_BLOCKED 做最多 2048-token 自由续写，共 16 次。
检验首次实际旧构造采用、转向、无决策和截断；不把短续写当完整解题
准确率，不根据局部均值自动扩展。8 题仅作行为桥接，不能充当独立确认。

## 研究决策

- 晚屏蔽仍存在具体旧路线偏向，重建后减弱，且效应跟随历史内容身份：
  支持原草稿之外的路径承担因果作用；再检验该解释能否预测自然续写。
- 晚屏蔽已经消除相关影响：优先考虑当前直接读取解释；不硬写成下游残留。
- 重建和晚屏蔽相近：当前实验不支持候选预测；不反复搜索层或幅度挽救。
- 两种读出同步变化，或身份对照只有普遍降置信：不能确认路线撤销特异性；
  判断是否有足够新的替代解释，避免把不断缩小的消融主张当最终贡献。

只按这一个主预测决定下一步，不在本轮并行开发门控、扩模型或跑 AIME。

## 相邻工作与待明确的新颖性

- [Contextual Drag](https://arxiv.org/html/2602.04288v1#S6)：已展示反馈/验证
  不足以完全消除拖曳，并提出状态重置猜想。
- [Hidden Error Awareness](https://arxiv.org/abs/2605.09502)：研究可解码
  错误信号及多种纠错干预的局限。不能把“识错不等于纠错”本身当新增发现。
- [How LLMs Detect and Correct Their Own Errors](https://arxiv.org/abs/2604.22271)：
  研究部分独立的评价信号及检测/纠错预测，不是我们的效果已经得到支持。
- [Thought Anchors](https://arxiv.org/abs/2506.19143)：研究关键推理句及其因果
  影响。我们的候选差异在于被明确否定的历史、共同晚屏蔽条件、下游状态
  建立路径及可撤销性，而不是再次发现某些历史句子重要。
- [Activation patching 方法与指标](https://arxiv.org/abs/2309.16042)。

以上是本次检索后的定位，尚不是穷尽文献后的首创声明。先完成针对
相邻工作方法的比较，再冻结主实验材料和结论边界。

方法比较已补入 [相邻工作与新颖性边界](route_revocation_positioning_20261010.md)。
当前批次能检验一个必要机制预测，单独得到“早阻断优于晚阻断”仍不足以
支撑 ICLR 级贡献；需要进一步解释内容相关的撤销失败，并预测自然推理行为。
