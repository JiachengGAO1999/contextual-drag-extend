# 路线撤销：相邻工作方法与新颖性边界

2026-10-10 查阅原文；这是针对候选命题的定位，不是穷尽检索或首创保证。

| 工作 | 已经研究的内容 | 本工作的候选差别与限制 |
|---|---|---|
| [Contextual Drag](https://arxiv.org/html/2602.04288v1#S6) | 错误历史造成性能下降，正确验证后仍可能失败；讨论 reasoning state reset，并做针对性训练缓解。 | “识错仍失败”与“需要 reset”都不是我们的新发现。需要给出具体历史作用路径及可检验的撤销预测。 |
| [Hidden Error Awareness](https://arxiv.org/html/2605.09502v1#S5) | 从隐状态预测错误；测试 steering、选择、重新纠错与正确轨迹状态替换，干预收益受限。 | 我们比较同文本、同后续读取条件下的状态形成路径；不训练错误探针、不把一个错误方向等同整个路线。其失败干预不能证明所有错误信号均无因果作用。 |
| [How LLMs Detect and Correct Their Own Errors](https://arxiv.org/html/2604.22271v1#S4) | PANL 的评价信息预测检测及部分纠错结果；patching/noising 检验其对错误检测的因果贡献和冗余。 | 不能把评价与后续改正有区别本身当新颖性。我们的待检验对象是已经收到否定反馈的特定旧构造如何继续影响采用。 |
| [Thought Anchors](https://arxiv.org/html/2506.19143v1#S5) | 推理句的重采样重要性、receiver heads 和全层全头 attention suppression，研究句间影响。 | 全层全头遮蔽已有先例。我们不以遮蔽操作本身为贡献，而以否定反馈后的历史路径、身份及撤销条件为对象。 |
| [Authority Before Utility](https://arxiv.org/html/2609.37474v1) | 在外部持久记忆中区分当前可使用性与检索效用，比较排除与有限惩罚；作者限定其替代诊断证据范围。 | “信息有用却不应继续使用／需要撤销”也是相邻命题。这里比较 Transformer 内相同可见文本的状态形成路径，而非外部记忆候选准入。不能宣称率先提出信息撤销。 |
| 项目已有 R3/R4，见 [2026-09-12 审阅](quick_validation/r3_r4_mechanism_review_20260912.md) | R3 保留完整 prefill，R4 阻断草稿后 queries；自然轨迹中出现恢复和损伤。 | REBUILD_BLOCKED 就是旧 R4。新批是受控功能检验，不是新增干预或对旧行为数据换名。 |

本轮有价值的候选证据链是：在相同反馈与文本下，晚阻断后具体旧构造仍影响
后续采用；这一影响来自此前形成的下游状态；它与评价输出的关系能解释何时
撤销失败，并预测未用于发现的自然续写。当前批次首先检查其中的路径与内容预测。

必须正视三个解释竞争者：

1. **熟悉度／复制优势。**旧表达式的概率增高未必表示推理路线被采纳。
   采用读出使用“作为我的解”的表达式续写，但仍需自由生成桥接。
2. **一般扰动与置信变化。**早阻断改变了较多计算；仅两个条件有差异不足以
   宣称功能分离。查看合法候选、错误候选 A/B 与判决的联合变化。
3. **固定文字的携带。**本批 critique 不重复旧式子，有利于隔离文本之外路径；
   但不能据此排除自然轨迹通过显式文字重新引入错误的机制。

A/B 早阻断后的身份不变是计算图性质；判决读出是在外部反馈及强制正确文本
之后保持判断的能力。两者都不能包装成“发现模型会识错但不会撤销”的证明。

若只有早／晚遮蔽差异而没有可解释的内容作用与自然预测，应重新判断 idea 的
研究价值，而不是继续通过搜索更多 heads 或缩小 claim 累积消融结果。
