# 参考解来源绑定：有限否证批次

## 为什么值得一次检验

公开反馈中出现了“批评者将参考解的具体论证归给求解者”的四题五条文字
证据。它指向诊断阶段的来源绑定，而不是默认求解者拒绝准确反馈。
此前的主体计算、资源身份与目标耦合实验不能验证这一新解释，也不应重跑。
详见[公开轨迹审查](public_feedback_friction_review_20261012.md#后续-cpu-进展参考解内容被归给待批改回答)。

工作假设：**正确参考解可能成为错误诊断的内容来源；批评者没有稳定地把
“参考里有什么”与“求解者写过什么”分开。** 需要同时检验内容来源与诊断
对象，不能只报告反馈不准确、提示改写提高分数或参考解压制正确路径。
这些一般现象已有研究。本批是一次可否定候选的测量，不是论文验证或方法 MVP。

## 独立材料已经落实

[Stepwise Verification and Remediation](https://arxiv.org/html/2407.09136v1)的
[公开数据](https://github.com/eth-lre/verify-then-generate/blob/main/dataset/dataset.json)
已下载到本地，共 1,002 条、612 个不同题目文本。它提供教师标注的首错位置、
错误说明、参考解及学生错误解答；1002 条的首错索引均与对应步骤文本一致。
仓库当前没有发布配对模型批改输出，因此不能仅用缓存完成新模型反事实。

每个题目文本取首条源记录，种子 20261005 打乱，固定前 64 题。不按模型效果、
是否出现参考词组或错误类别挑题。使用原 `student_incorrect_solution`，
不是把参考解改写成错误解；不把教师错误说明放进模型提示。
64 题覆盖七类既有教师标注，按独立题目报告，不把批评条数作为样本量。
原始学生材料本身来自既有生成数据，不声称代表所有自然推理或真实学生。

## 196 次短批改，分别回答两个问题

### 独立材料：64 题 × 三条件 = 192 次

| 条件 | 输入及用途 |
| --- | --- |
| NO_REFERENCE | 题目与固定学生回答；测量没有参考内容时的批改表现 |
| REFERENCE | 再提供正确参考解；检查是否出现具体的参考内容误归属 |
| GROUNDED_REFERENCE | 相同参考解，加上引用学生原话、区分参考建议与学生断言的要求；作为已有来源核对思想的强基线 |

三个条件的题目与学生回答完全相同。反馈至多指出三项错误、六句话，不生成
完整修订答案。不因为有参考条件整体更差就宣称来源绑定：参考同时改变数学
求解信息，且第三条件改变提示要求；必须直接核查错误归属的内容。

教师标签只标注首错，不能将其他有效错误诊断自动判错。评分时分别记录：
首错是否被识别、是否把未出现的具体断言归给学生、是否只是提供新建议，
以及无法确定的情况。词组重叠、符号出现、引用核对只是审阅线索。
只对同题条件差做比较；若报告区间，以题目为重采样单位。

### 来源操纵：两个既有示例 × 原参考／改名参考 = 4 次

复用已检查的函数题 h→u、十二边形参考局部斜率符号 k→v。只改变参考解的
辅助符号，题目、学生回答、参考的数学内容及正确答案保持相同。

检查不存在的“学生断言”是否跟随参考独有符号改变。正常用新符号提供提示
不算失败；不能只统计新符号出现率。这两个例子来自探索材料，只用于检验
可区分的来源预测，不是独立确认集，也不能支持总体效应或神经机制结论。

## 如何作出决定

### 在结果出来前明确判读对象

每条批改分开判断三件事：所说数学内容是否正确、学生是否真的写过它、
它是否只出现在参考解中。不能因一句话能被整个输入中的某处支持，就认为
“你写过这句话”的归属正确。例如学生只写“按斜率计数”，参考写“两个斜率
的计数相同，所以乘3”，批改却说“你声称计数相同并乘3”：这是要检验的
错误归属。“你需要解释各斜率的计数”则可能是合理指出缺漏，不能算同类错误。

仅将明确或语义上无歧义的学生归属列为支持证据；提示新思路、引用参考解、
对学生内容的合理概括和无法判定的表述分别保留。教师首错标签用于检查
诊断是否对准实际错误，不能代替逐句核对。学生没有采用参考的解法也不等于错。

这里争取的新增解释是“正确参考的具体内容进入了针对另一对象的错误归属”，
需要来源操纵的支持；仅观察到批改不忠实仍属于已知反馈幻觉。
[反馈忠实性研究](https://www.educationaldatamining.org/edm2024/proceedings/2024.EDM-short-papers.49/)
已经测量与学生材料不符的批评；
[参考评分失效研究](https://arxiv.org/html/2601.07506v1)检验参考与参数知识冲突；
[知识来源探测研究](https://arxiv.org/html/2602.22787v1)区分上下文与参数知识的贡献。
这些不是相同的源对象对照，但足以排除“首次发现幻觉／来源问题”的宽泛主张。

另已检查公开Feedback Friction当前代码中的调用与提示构造：学生响应作为
`Most Recent Answer`，正确参考作为`correct reasoning process`，未发现这条
路径把两个变量直接交换。公开代码版本未必是生成数据的版本，因此只能降低
一个实现伪影的可能性，不能据此认证原始服务调用。

若独立题目没有明确误归属，或改名对照不支持预期来源运输，记录相应证据，
不追加相同小案例、不同别名或提示搜索来挽救该版本命题。截断或未完成导致
无法判定时如实报告不足，不自动补跑。

若两部分出现一致支持，才评估更大范围的来源绑定机制及它是否影响修订。
本批没有求解者重试，故不能证明批评导致持续失败或提高最终解题准确率。
GROUNDED_REFERENCE 的收益即使成立，也先视为已有强基线，不能作为新方法
命名。仍需确认区别于已有反馈幻觉、步骤对齐及 LLM 评价偏置工作。
